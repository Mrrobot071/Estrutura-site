# Estrutura-site

Estrutura base para sites estáticos — ponto de partida reaproveitável para novos projetos front-end.

## Estrutura

- `index.html` — página principal com layout pronto

## Como usar

1. Clone o repositório ou copie os arquivos
2. Ajuste conteúdo e estilos conforme o projeto
3. Publique em qualquer hospedagem estática

## Tecnologias

- HTML5
- CSS3
